## 1. System Architecture
The simulation moves from a "Feature-Based" model to a "Window-Based" State Machine.

### The 3-Layer Logic
1.  **The Inputs (Static):** Parsing `DSTVData` into geometry.
2.  **The Brain (Planning):** The `WindowIndexer` converts infinite geometry into discrete `MachineCycle` objects.
3.  **The Body (Execution):** The `PCR41_Controller` executes cycles using a "Safe-Plane" Motion Model and a "SafetyPLC" Interlock.

---

## 2. Core Components

### A. The Brain: `WindowIndexer`
**Responsibility:** "God Class" for manufacturing logic.
**Input:** `DSTVData` (entire beam).
**Output:** List[`MachineCycle`].

**Key Logic:**
1.  **The Window:** Rigid 200mm Processing Window (X=0 to X=200).
2.  **Greedy Packing:** Fit as many features into the window as possible.
3.  **Oversized Handling (The Bisect):**
    *   IF a Feature (e.g., Cope) > 200mm:
    *   Action: Create `MachineCycle(type=PROCESS, ...)` for the first 200mm.
    *   Action: Create `MachineCycle(type=SEVER, ...)` to cut the slug.
    *   **CRITICAL CONSTRAINT:** The `SEVER` cycle path length must be calculated from `DSTVData.profile_height` (Flange Cuts) + `DSTVData.web_thickness` (Web Cut). **DO NOT use magic numbers. Use Worst Case Profile Height/Width Values.**
    *   Action: Create `MachineCycle(type=INDEX, ...)` to reposition.

### B. The Nervous System: `SafetyPLC`
**Responsibility:** Deterministic State Locking (Replacing `simpy.Resource`).
**Location:** `simulation.core.machines.subsystems.logic.safety_plc.py` (New File).

**Variables:**
*   `robot_state`: Enum [`HOME`, `MOVING_TO_SAFE`, `IN_WINDOW`, `FAULT`]
*   `feeder_state`: Enum [`IDLE`, `MOVING`, `LOCKED`]

**Logic (The Handshake):**
*   **Robot Entry:** Can only enter `IN_WINDOW` if `feeder_state == IDLE`. Locks Feeder.
*   **Feeder Move:** Can only switch to `MOVING` if `robot_state == HOME`. Locks Robot.
*   **Implementation:** Use `simpy.Event` for `robot_is_home` and `feeder_is_idle` to allow actors to `yield wait`.

### C. The Body: Motion Physics
**Responsibility:** High-fidelity time estimation.

#### 1. Transition Cost Matrix
**Location:** configuration (JSON or Class Constant).
**Structure:** 4x4 Matrix (Top, Bottom, Front, Rear).
**Logic:**
*   Same Face (Top -> Top): Cost = 0s (Handled by Rapid Trajectory).
*   Adjacent (Top -> Front): Cost = 1.5s.
*   Opposite (Top -> Bottom): Cost = 4.0s (Requires full retract).
*   **Usage:** Added to `MachineCycle` duration during the `indexer.plan_beam()` phase OR calculated dynamically by the Robot actor during execution. *Decision: Calculate in Robot Actor for runtime fidelity.*

#### 2. Process Physics (`ProcessEnergyCalculator`)
**Responsibility:** Calculate Cutting Speed (mm/min).
**Input:**
*   `Material`: `mech_core.standards.materials.steel.StructuralMaterial`
*   `Tool`: `eoa_tools.FiberLaser` (Power KW)
**Formula:**
$$ Speed = \frac{Power \times Efficiency}{Enthalpy \times Area} $$
*   Area = Kerf Width * Material Thickness.
*   Enthalpy = `specific_melting_energy_volumetric` (from `mech_core.analysis.heat_transfer.phase_change`).

## 2. Technical Reference Patterns ("Golden Snippets")

### Pattern A: The SafetyPLC Handshake (`simpy.Event` State Machine)
Instead of `simpy.Resource`, we use `simpy.Event` flags to model the PLC inputs/outputs.

```python
import simpy
from enum import Enum, auto

class RobotState(Enum):
    HOME = auto()
    MOVING_TO_SAFE = auto()
    IN_WINDOW = auto()

class FeederState(Enum):
    IDLE = auto()
    MOVING = auto()

class SafetyPLC:
    def __init__(self, env):
        self.env = env
        # Safe State Flags (Initially Safe)
        self.robot_is_home = env.event()
        self.robot_is_home.succeed() # Start at HOME
        
        self.feeder_is_idle = env.event()
        self.feeder_is_idle.succeed() # Start at IDLE

    # Robot Logic
    def lock_robot_entry(self):
        # Wait for Feeder to be IDLE
        yield self.feeder_is_idle
        # Lock Feeder (Clear the flag so Feeder waits)
        self.feeder_is_idle = self.env.event() 
        
    def release_robot_entry(self):
        # Signal Feeder it can move
        self.feeder_is_idle.succeed()

    # Feeder Logic
    def lock_feeder_move(self):
        # Wait for Robot to be HOME
        yield self.robot_is_home
        # Lock Robot (Clear the flag)
        self.robot_is_home = self.env.event()
```

### Pattern B: Process Energy Calculation
Integration with `mech_core` for cutting speed.

```python
from engineering_tools.mech_core.analysis.heat_transfer.phase_change import specific_melting_energy_volumetric
from engineering_tools.mech_core.standards.units import ureg

class ProcessEnergyCalculator:
    @staticmethod
    def calculate_cutting_speed(material, thickness_mm: float, tool_power_kw: float, tool_efficiency: float, kerf_width_mm: float) -> float:
        # 1. Enthalpy (J/mm^3)
        enthalpy_vol = specific_melting_energy_volumetric(material) # Returns Pint Quantity
        
        # 2. Volume Rate Required (mm^3/s)
        # Power = Energy/Time -> Power = (Energy/Vol) * (Vol/Time) 
        # Vol/Time = Power / (Energy/Vol)
        effective_power = (tool_power_kw * tool_efficiency) * ureg.kilowatt
        removal_rate = effective_power / enthalpy_vol
        
        # 3. Linear Speed (mm/s)
        # Removal Rate = Speed * Width * Depth
        cross_section = (kerf_width_mm * ureg.mm) * (thickness_mm * ureg.mm)
        speed = removal_rate / cross_section
        
        return speed.to(ureg.mm / ureg.min).magnitude
```

### 3.3. Update: `simulation/core/machines/PCR41/indexer.py`
Refactor `Indexer` to `WindowIndexer`.
*   **Method:** `plan_beam(dstv_data: DSTVData) -> List[MachineCycle]`
*   **Logic:**
    *   Iterate features sorted by X.
    *   **Window Limit:** 200mm.
    *   **Bisect Logic:**
        *   `if feature.length > 200:`
        *   Gen `PROCESS` (start to 200)
        *   Gen `SEVER` (at 200). **Length = max(dstv.profile_height, dstv.web_thickness)**.
        *   Gen `INDEX` (move window).
        *   Repeat.

### 3.4. Update: `simulation/core/machines/PCR41/pcr41.py`
Integrate the components.
*   **Init:** Instantiate `SafetyPLC` and `WindowIndexer`.
*   **Run Job:**
    *   Get `cycles` from Indexer.
    *   Iterate cyles.
    *   If `INDEX`: Call `plc.lock_feeder_move()`, move feeder, `plc.release_feeder_move()`.
    *   If `PROCESS`: Call `plc.lock_robot_entry()`, move robot, `plc.release_robot_entry()`.
*   **Motion:** Apply `TransitionCostMatrix` for Z-axis moves (e.g., `simpy.timeout(TR_MATRIX[face_a][face_b])`).
